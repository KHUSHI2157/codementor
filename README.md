# 💻 CodeMentor

### Learn. Code. Improve.

CodeMentor is a student-focused programming learning platform designed to help beginners learn programming concepts, practice coding problems, and track their learning progress through a structured and interactive interface.

## 🚀 Features

* 📚 Structured programming learning paths
* 💻 Programming practice problems
* 🔤 Support for C, C++, Python and JavaScript
* 🧩 Difficulty-based problem organization
* 👨‍💻 Interactive coding editor interface
* 📊 Learning progress dashboard
* 🔥 Streak and XP-based learning concept
* 💡 Hints and guided learning
* 📱 Responsive interface for different screen sizes

## 🛠️ Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* React Router
* Lucide React
* Git & GitHub

## 🎯 Purpose

CodeMentor was created to provide beginners with a focused environment where they can learn programming concepts and practice coding without having to switch between multiple platforms.
